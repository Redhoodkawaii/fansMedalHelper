# GitHub Actions 每日报告

## 第一次启用

1. 将本次更新合并到仓库默认分支。打开 GitHub 仓库的 **Actions**，如果页面提示需手动为 fork 启用工作流，请点击启用。
2. 选择 **Daily Fans Medal Report → Run workflow**，选择默认分支并运行。在执行详情中点开 **Generate simulated daily report** 查看模拟等级、亲密度、观看进度和估算积分。
3. 再运行一次，同一个北京时间自然日会显示跳过。工作流串行运行，并用 GitHub Actions 缓存记录当日完成。缓存过期、被清除或写入失败后可能重新生成模拟报告。GitHub 可能延迟执行定时任务，公开仓库连续 60 天无活动时也可能停用定时任务。

默认每天约北京时间 20:10 运行。模拟任务无需 Secret，只读访问 GitHub 仓库。每次成功运行的公开日志只有固定模拟数据。旧版 **Sync Fork** 可能将默认分支更新为直接上游的代码，使用前请先核对工作流变更。

## 使用自己的勋章数据

在 B 站官方客户端登录，由你完成登录验证。打开装扮中心的粉丝勋章页面，选一个主播，记录等级和亲密度。可见时一并记录当日观看分钟数，不可见时填 `null`。在本项目目录创建 `medal-snapshot.json`，用你看到的数值替换下面的示例。

```json
{"level": 12, "intimacy": 830, "watch_minutes": 15}
```

用 Python 3.11 运行 `python run_actions.py --snapshot medal-snapshot.json`。报告保存在 `daily-reports/manual-日期.json`，终端只显示生成结果。同日重复运行会保留首份报告。数值文件和报告目录已列入 Git 忽略规则，请留在本机。若已有旧版 `BILI_ACCESS_KEY`，合并后可在 **Settings → Secrets and variables → Actions** 删除。当前工作流无需提供 Cookie、登录令牌或账号授权。

## 截至 2026-11-18 查到的规则

哔哩哔哩直播最近查到的全站通用改版公告自 2025-09-08 生效。等级统一为 1–120 级。直播观看每 5 分钟基础奖励 6 点，当日最多 30 点。报告按该公式估算，实际进度和结算以官方页面为准。公告未把点赞、弹幕或签到列为新版通用亲密度来源。若页面有活动任务，以活动说明为准。[官方改版公告](https://www.bilibili.com/opus/1100097465625870441)

公告还列出付费灯牌每日首个 6 点，电池礼物和醒目留言每电池 1 点，视频投币每硬币 10 点（每日最多 100 点），充电每 B 币 10 点，大航海有 1.5 倍加成。粉丝团、舰长、提督、总督的勋章每日总上限分别为 2 万、25 万、100 万、400 万。投币会消耗站内硬币，其余付费项目由你在官方页面决定并确认。[官方改版公告](https://www.bilibili.com/opus/1100097465625870441)
